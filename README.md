# DevOps Git Project - Task 4

## Objective
To practice Git version control with branching, pull requests, tags, and documentation.

## Branches
- main → Stable production code
- dev → Development branch
- feature/hello-world → Sample feature

## Git Workflow
1. Initialize repo and add remote  
2. Create branches (main, dev, feature)  
3. Commit and push feature branch  
4. Create Pull Request (feature → dev → main)  
5. Tag release version (v1.0)  

## Tools Used
- Git
- GitHub
